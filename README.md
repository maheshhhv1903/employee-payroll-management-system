# Employee Payroll Management System – Core Java (Console Application)

A simple and fully functional **Employee Payroll Management System** built using **Core Java**, **OOP Concepts**, and **JSON file storage** using **Gson** library.

This project helps manage employee salary details such as:
- Adding employees  
- Viewing employees  
- Updating salary  
- Deleting employees  
- Calculating Gross Salary (Basic + HRA + DA)

---

## ✨ Features

✔ Add Employee  
✔ View Single Employee  
✔ View All Employees  
✔ Update Salary  
✔ Delete Employee  
✔ JSON File Storage (employees.json)  
✔ Clean OOP Structure  
✔ Works fully in terminal (Console-based Project)
